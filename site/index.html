What happens when your agent says it's done

  1. Kane drives the flowThe flows in senyap.config.json, in a real Chrome, including a reload to check the result stuck.
  2. Senyap reads the evidenceThe HAR and console log Kane wrote into the run's evidence pack, then seals a pack of its own with a senyap metric catalog.
  3. Kane judges itkane-cli evidence verdict runs senyap.policy.yaml: no hidden 5xx, no dropped requests, no console errors, no calls to another environment, no false green.
  4. Kane explains itOnly when the evidence shows a failure, Kane runs again with its DevTools checks and returns a confirmed product bug (740) with a root cause.
  5. The agent fixes itThe stop is blocked with a brief: what failed, the request, the response, and a link to the Kane run. After three tries a human is asked to look.
  6. The flow is lockedsenyap lock saves the clean flow as a *_test.md that replays from cache with adaptive heal off, so a later regression can't be healed away.

Install it in the repo your agent works in

Senyap drives no browser of its own. You need Kane CLI and a TestMu AI account.

# once
npm install -g @testmuai/kane-cli
kane-cli login

# in your app's repo
npx senyap init --agent claude   # or codex, cursor, all

init writes senyap.config.json, registers the Stop hook (Claude Code and Codex block with a reason; Cursor gets a follow-up message), and installs Kane's own agent skill so the agent can call Kane while it fixes.

Or point it at the demo

Built on Kane CLI's own pieces

Every verdict comes from Kane. Where Kane fell short, Senyap works with it instead of around it.

kane-cli run --agent
Drives each flow; Senyap reads the NDJSON run_end: result code, summary, Test Manager link, credits.
--bug-detection continue
Kane separates a product bug (740) from a broken test.
Evidence packs
The network.har and console.ndjson Kane records in every run are the facts Senyap judges.
evidence-cli producer catalog
Kane's policies can't read logs, so Senyap seals its own pack with metrics.silent.* and metrics.false_green_tests.
kane-cli evidence verdict
Kane enforces senyap.policy.yaml on those metrics.
*_test.md, testmd run
Locked flows replay from cache with --no-adaptive-heal, gated on metrics.heal.healed_tests so a heal can't hide a regression.
kane-cli install skill
The agent gets Kane while it fixes.
